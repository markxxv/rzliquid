# rzliquid

Интерактивная арт-инсталляция на three.js: жидкая ртуть, разбитое стекло, хромированная проволока.

- **Ртуть** — SDF-рейтрейсинг во фрагментном шейдере (плавное слияние капель, отражения хрома, вторичный отскок луча).
- **Физика** — пружинная модель с поверхностным натяжением; курсор расталкивает ртуть, зажатие притягивает, быстрый взмах отрывает капли, которые потом втягиваются обратно.
- **Окружение** — процедурная фотостудия (cube map), вращается за курсором, поэтому блики скользят по хрому.
- **Стекло / проволока / пузыри / осколки** — меши с кастомными шейдерами, проволока — верлет-канаты.

Запуск локально: любой статический сервер, например `python3 -m http.server`, затем открыть `http://localhost:8000`.
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

three.js подключается из CDN (jsDelivr) через importmap в `index.html`.
Параметры URL: `?debug` — FPS, `?pr=1` — зафиксировать pixel ratio.
